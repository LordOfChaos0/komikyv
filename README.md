# Коми кыв — интерактивная платформа изучения коми языка

Веб-платформа для изучения коми языка с AI-тренажёрами, геймификацией
и конструктором учебных модулей. Реализована в рамках практики
по веб-технологиям и соответствует рекомендуемому уровню SRS-требований.

## Возможности

- **Учебные модули** — уроки с теорией, упражнениями 5 типов (выбор ответа,
  перевод, пропуски, сопоставление, аудио) и последовательным открытием
- **Диалоговый тренажёр (LLM)** — общение на коми языке с обратной связью
  по грамматике и переводом [RU:]
- **Тренажёр произношения (ASR)** — запись голоса через микрофон и оценка
  точности произношения по Levenshtein-расстоянию
- **Озвучка слов (TTS)** — синтез речи для коми лексики
- **Интервальные повторения (SM-2)** — умное планирование повторения слов
- **Игры** — Слово-матч, Слово-пазл, Скоропечать, Карточки памяти
- **Справочники** — интерактивный алфавит (35 букв), грамматика, пословицы,
  сказки, культура Коми
- **Геймификация** — XP, уровни, серии занятий (streak), 12 достижений, рейтинг
- **Конструктор модулей** — преподаватели создают модули с уроками, словарём
  и упражнениями; модерация публикаций админом
- **Роли** — гость / студент / преподаватель / администратор (RBAC на всех
  защищённых API)

## Технологии

| Слой | Стек |
|------|------|
| Фреймворк | Next.js 16 (App Router, standalone output) |
| Язык | TypeScript 5 (strict) |
| UI | React 19, Tailwind CSS 4, shadcn/ui, framer-motion |
| Состояние | Zustand (SPA-навигация), TanStack Query (данные) |
| БД | Prisma ORM 6 + SQLite (20 таблиц, 49 индексов, soft delete) |
| Валидация | Zod (двусторонняя: клиент + сервер) |
| AI | z-ai-web-dev-sdk (LLM / TTS / ASR) |
| Почта | nodemailer (подтверждение email, восстановление пароля) |
| Документация API | OpenAPI 3.0 + Swagger UI на `/api-docs` |
| CI/CD | GitHub Actions (линт, typecheck, build, deploy) |

## Безопасность

- Пароли: scrypt (16-байт salt, timing-safe сравнение)
- Сессии: JWT (HS256) в httpOnly cookie, 7 дней
- CSRF: double-submit cookie на все мутации
- Rate limiting: login 5/мин, восстановление пароля 3/мин
- Security-заголовки: CSP, HSTS, X-Frame-Options, Permissions-Policy
- RBAC-барьеры на всех защищённых маршрутах (`requireRole`)
- Дополнительный токен админ-панели (`ADMIN_ACCESS_TOKEN`)
- Аудит-логи: AuthLog, AuditLog, ModerationLog
- Соответствие 152-ФЗ: согласие на обработку ПД, soft delete, аудио не хранится

## Быстрый старт

```bash
bun install                # зависимости
cp .env.example .env       # конфигурация (минимум: DATABASE_URL, JWT_SECRET)
bunx prisma generate       # Prisma-клиент
bun run dev                # dev-сервер на http://localhost:3000
```

Демо-аккаунты (создаёт seed):

| Роль | Email | Пароль |
|------|-------|--------|
| Админ | admin@komikyv.ru | `Admin123!` |
| Преподаватель | teacher@komikyv.ru | `Teacher123!` |
| Студент | student@komikyv.ru | `Student123!` |

Production-сборка:

```bash
bun run build
cd .next/standalone
cp -r ../../.next/static .next/ && cp -r ../../public .
node server.js
```

## Документация API

После запуска: **`/api-docs`** — интерактивный Swagger UI (73 операции).
Спецификация: **`/api/openapi.json`** (OpenAPI 3.0).

## Структура проекта

```
src/
├── app/
│   ├── api/            # 53+ REST-маршрута (auth, модули, SRS, admin, ...)
│   ├── api-docs/       # Swagger UI
│   ├── error.tsx       # Кастомная 500 «Технические работы»
│   ├── not-found.tsx   # Кастомная 404 с поиском по платформе
│   └── page.tsx        # SPA-оболочка (единый маршрут /)
├── components/
│   ├── views/          # 38 view-компонентов (student/teacher/admin)
│   └── ui/             # 48 shadcn/ui-компонентов
├── lib/                # auth (scrypt+JWT), db, mailer, SRS, api-client
└── proxy.ts            # CSRF, rate limiting, CORS, админ-токен
prisma/schema.prisma    # 20 таблиц предметной области
.github/workflows/      # CI + deploy
```
